# Compiled

Compiled binary files for [@rei-network/binding](https://github.com/REI-Network/binding)

## Compiler Environment

- darwin:
  - x64: `Apple clang 13.0.1`
  - arm64: `Apple clang 13.0.1`
- linux:
  - x64: `gcc 8.5.0`(`GLIBC 2.28`, `GLIBCXX 3.4.25`)
